# Predict-and-Search Framework

Implementation of the paper "A GNN-Guided Predict-and-Search Framework for Mixed-Integer Linear Programming".

## Environment

The original repository targeted an older CUDA-based stack. This repo now includes a simpler modern environment that is easier to reproduce on a typical Linux machine:

- Python 3.10
- PyTorch 2.4
- PyTorch Geometric 2.6
- PySCIPOpt 6.x
- gurobipy 13.x

Create and activate the environment with Conda:

```bash
conda env create -f environment-modern.yml
conda activate milp-ps
```

Notes:

- The provided environment uses CPU by default. The code still detects CUDA automatically if your local PyTorch build supports it.
- Running the Gurobi-based scripts requires a working Gurobi installation and license.

## Repository Layout

```text
dataset/                 generated bipartite graphs and solutions for training
instance/                local MILP instances used for generation, training, and testing
models/                  pretrained model checkpoints
logs/                    solver logs generated by evaluation scripts
pretrain/                saved checkpoints from training
train_logs/              training logs
```

Tracked pretrained checkpoints currently include:

- `models/CA.pth`
- `models/IP.pth`
- `models/IS.pth`
- `models/LB.pth`

## Data Preparation

Instance generation depends on the task:

- `IS` and `CA` instances can be generated with [Ecole](https://www.ecole.ai/).
- `IP` and `WA` instances come from the ML4CO 2021 competition generator.

After preparing raw instances, place them under the appropriate task directory inside `instance/`. The current scripts resolve task directories in either of these forms:

- `instance/<TASK>/test`
- `instance/<task>/test`
- `instance/<TASK>`
- `instance/<task>`

Then generate graph data and solutions with:

```bash
python gurobi.py
```

Generated training assets are written under `dataset/`.

## Training

Set `TaskName` in `trainPredictModel.py`, prepare the matching dataset folders, then run:

```bash
python trainPredictModel.py
```

Training outputs are written to `pretrain/` and `train_logs/`.

## Evaluation

The three main evaluation entry points are:

```bash
python PredictAndSearch_SCIP.py
python PredictAndSearch_GRB.py
python FixingStrategy_SCIP.py
```

By default the repository is configured around the `CA` assets that are currently present locally. If you switch tasks, update `TaskName` in the corresponding script and make sure the matching model checkpoint and instance directory exist.

Solver logs are written under `logs/`.
